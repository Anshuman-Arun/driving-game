# Track A integration notes (2026-11-21)

The current feature branch owns **only** `project.godot`, `addons/`, `scenes/`, `scripts/vehicle/`, `tests/core/`, and `docs/DEPENDENCIES.md`. No worldgen/racing/traffic/art agent files and no shared project status docs were edited.

## Implemented — source committed, gameplay not engine-verified

- F5 entry `scenes/bootstrap/main.tscn` -> `scenes/prototypes/driving_test.tscn`, generated by `scripts/vehicle/driving_test.gd`.
- `DrivingTestWorld` produces 500×500 m heightfield, collision-capable asphalt and dirt shoulder ribbon, S-bends, long acceleration section, hairpin, lane/edge markings, barriers, trees, sign posts, sunlight and invisible boundaries.
- `PlayerCarFactory` creates one fictional Vela GT from primitive meshes, true GEVP `Vehicle` RigidBody3D and four GEVP `Wheel` RayCast3D contact/suspension nodes, RWD engine, gearbox, tire contact groups.
- `DriveInput` maps analog controller triggers and left stick alongside keyboard; `VehicleAdapter` applies input, exposes speed (m/s), gear and zero-velocity righting/reset. `DrivingChaseCamera` uses speed FOV, smoothing and ray camera clearance.
- HUD: km/h / gear / contact state, control legend, pause overlay. C / right-stick click camera; R / Y reset; ESC / Menu toggle pause.

## Important incomplete dependency integration

A future integrator must replace / reconcile the **independent runtime road spline and terrain mesh** with World agent's `data/world/road_graph_v1.json`, official Road Generator `RoadManager`/generated `RoadContainer` collision, and a **Terrain3D v1.1.0** native terrain and connector without modifying that road graph. This branch does not load or edit unmerged World Agent data. The Road Generator editor plugin is vendored but not exercised in the scene. Terrain3D native release binaries are not bundled; the plugin was not loaded. We deliberately did not invent a successful three-add-on integration. The standalone Mesh/StaticBody path remains as a fallback if plugin blockers arise.
