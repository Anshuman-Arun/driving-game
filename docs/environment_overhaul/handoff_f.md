## Headless
Python 3.10+, Node, Git LFS, checksum-pinned Godot 4.7.2 stable. On a fresh checkout:

    git lfs pull
    python3 -m unittest discover -s tests/environment_overhaul -p 'test_*.py' -v
    python3 tests/environment_overhaul/qa.py --mode baseline --out /tmp/aster-env-baseline

Workflow `.github/workflows/environment-overhaul-qa.yml` triggers path-scoped pull requests and manual dispatch; it retains the pinned installer and the existing standalone, data, traffic and production audio suites. Baseline root tests are the existing ten scripts unchanged. Canonical traffic junction diagnostics remain a distinct manual opt-in (known baseline failures). Each owned command has a bounded timeout, actual log, strict return status and parse/script-error gate. CI root job uses full history for the protected-path comparison. Logs are not uploaded as large artifacts; the runner prints tail and JSON status. No external assets are imported by F.

After candidate packages land, run:
    
    python3 -m pip install -r content/scenery/environment_overhaul/requirements.txt
    python3 tests/environment_overhaul/qa.py --mode integrated --prepare-mask --out /tmp/aster-env-integrated

Pass each agent's actual test argv as repeated `--agent-command '["godot","--headless","--path",".","--script","res://..."]'` and its actual deterministic generator invocation as `--rebake-command '["python3","..."]'`. The runner now discovers the actual A–E test paths from their read-only branch handoffs and executes them once present. Integrated mode requires those paths. `--prepare-mask` invokes C's real pinned generator only when the package is wholly absent; partial/corrupt packages fail rather than being overwritten. Integrated mode automatically rebakes twice into independent temporary output directories using the exact manifest seed/tuning and requires byte-identical mask, manifest, optional understory and statistics, leaving the accepted package intact. Alternatively supply --agent-manifest with a JSON list of argv arrays; integrated CI automatically reads tests/environment_overhaul/agent_commands.json if supplied by the coordinator. Rebake checks both generated mask payloads against the original exact bytes, so run on a disposable checkout. Without a generator, baseline determinism is N/A; integrated mode fails. Candidate manifest presence, mask schema/hash/coordinate orientation, asset inventory and available payloads, finite understory positions, exact triangle fixture (including shoulder/deck clearance), real candidate transforms, preset cycling, interaction, missing mask/invalid world, shutdown and same-seed traversal are checked. Asset path hashes require actual bytes, not LFS pointer text. Integrated mode resolves every recorded source within the checkout, requires the five canonical source hashes, and verifies understory/statistics/generator digests where provided.

## Local graphical capture (Windows)
Use a clean checkout, actual 4.7.2 console executable, real Forward+ GPU, LFS payloads imported, desktop large enough for a native 1920x1080 window. Use same graphics driver, monitor, refresh, resolution, fixed scene time, preset, settings and input. From repo root in PowerShell:

    $godot = 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe'
    & $godot --headless --path . --editor --import
    .\tests\environment_overhaul\capture.ps1 -Godot $godot -Output C:\qa\cedar-base -Site cedar
    .\tests\environment_overhaul\capture.ps1 -Godot $godot -Output C:\qa\cedar-candidate -Site cedar -Mode candidate -Features a,d,e
    python tests/environment_overhaul/report.py C:\qa\cedar-base C:\qa\cedar-candidate --out C:\qa\cedar-report.json

Baseline and candidate can be captured on the same integrated commit with explicit opt-in adapters and no root wiring. The capture harness now temporarily removes only kind-2 legacy grass groups from the live QA-session vegetation dictionaries, retains all other plants/scenery, and restores the removed groups on exit. It fails closed if the pinned legacy interface changes. Coordinator should replace this test-only adapter with a public reversible grass-only switch after integration, and provide a real traffic state hook; baseline root does not expose an integrated traffic toggle in the inspected driving script. Traffic is recorded unverified unless the coordinator exposes live state through drive metadata environment_qa_traffic_state (set to enabled only when actually enabled). Audio checks the actual VehicleAudio node and unmuted/nonzero master bus; verify actual audible car and environment locally. The report refuses final budget acceptance if traffic/audio are unconfirmed or if screenshots, frame continuity, duration, counters, actual starting camera pose, scene state, hardware, feature selection, grass isolation, or same-commit matching are invalid. PNG data chunks, CRCs, image dimensions, zlib stream and SHA-256 of all three artifacts are verified. Moving acceptance requires at least half of recorded time within declared 40–60 or 100–136 mph band; target speed alone is not evidence. D defaults to a bounded 200 m pilot around the capture pose and E selects only verified production Senna paint shader surfaces. Use -Interaction on both runs to compare the same interaction intent; baseline has no candidate interaction. PowerShell bounds engine execution and records Windows driver info only on an exact adapter-name match. The rewritten PowerShell launcher is separately tested using `capture.ps1 -SelfTest` on Windows PowerShell 5.1 and PowerShell 7: native argv with spaces, empty strings and trailing slash, flag validation and timeout. These tests need no Godot/GPU. They do not establish graphical acceptance. No GPU metrics are synthesized.

All five sites use the exact visual_compare road anchors (cedar, valley, alder, ridge, eastwater). `-Scenario stationary` parks and freezes after settling; `offroad` locates a finite surface outside actual pavement/shoulder clearance. `manual` freezes the settled chassis during warmup and unfreezes when CAPTURE START prints; drive matching routes for at least 60 seconds with traffic/audio on. `route` drives the actual Senna using existing vehicle-world pure-pursuit controls and a deterministic connected successor chain, respecting lane speed limits and curvature and braking at its end; not a teleport or camera flythrough. Route speed and route progress are logged; short connected routes can finish before the capture ends, and a departure causes braking. Review trajectory and actual speed before using moving comparisons. Use `-SpeedMps 17.9` to `26.8` (40–60 mph), and only on verified safe straight routes/manual runs 44.7–60.8 m/s (100–136 mph). No high-speed control reliability has been verified; do not treat lane target speed as achieved speed. Repeat Cedar and Green Valley first, then all five regions, off-road and moving. Compare A/D/E individually before combined. Start Medium native; vary density and range with -OptionsFile C:\qa\options.json (JSON object keyed by a,d,e; A pilot_bounds accepts [x,z,width,height], seed defaults to 1234); options are recorded in metadata. Low's reduced resolution scale is not interchangeable with Medium.

Output: real start/end PNG after frame_post_draw, frames.csv raw process-frame wall-clock intervals, GPU/CPU viewport timing (blank for unsupported/zero), global draw calls/primitives/VRAM (engine counters, not whole-system GPU memory), speed/gear/world position/FOV, visible cover count sampled once a second, metadata with commit, preset, renderer, GPU/CPU and driver where available, scene pose, flags, last cover stats and completion flag. Capture files written outside repository and temporary save profile deleted on orderly exit. Screenshot time excluded from measurement. No headless screenshot or FPS accepted. External driver overlays, audio and display settings need owner verification. The raw interval is not OS compositor presentation telemetry; actual dropped present frames are unavailable. Report computes interpolated p50/p95/p99, mean FPS and 1% low = 1000 / mean of slowest ceil(1% of valid intervals), counts invalid/missing samples, compares metadata and moving trajectory at matched elapsed seconds (provisional 10 m position and 3 m/s speed p95 tolerances, at least 48 matched seconds and 80% moving frames). Preview-only observed timing deltas may be printed even when acceptance is blocked; no visual pass. Target Medium p95 <= 16.67 ms and provisional p99 <= 25 ms. Owner should judge visuals, actual driving, traffic/audio, GPU and VRAM. Prior scenic report was below 60 FPS; no new measurements here.
