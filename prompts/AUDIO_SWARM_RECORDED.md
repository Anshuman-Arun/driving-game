### A — Bus and camera mix (mix/)
Build a dedicated AudioBusLayout resource and mix controller. Master gentle compressor (start threshold -16 dB, ratio 2:1, attack 15ms, release 120ms) plus limiter ceiling -1 dB if supported; verify actual Godot properties and true-peak separately. Engine_Exhaust -> Master, Engine_Intake -> Master, Exhaust_Reflection -> Master, Tires -> Master (HP ~120 Hz), Wind_Chassis -> Master (HP/EQ), Ambience, Music, UI -> Master. Godot bus send is a single downstream route, not independent aux routing: use a separate low-level wet-only reflection player/effect path; do not route the entire dry exhaust through a fake second send. Start gains Exhaust -6, Intake -12, Reflection -18, Tires -10, Wind -14, Ambience -20, Music -18, UI -12 dB; tune listening and peak measurements. Use listener-centered player engine mix if spatial attenuation makes it inaudible; for exterior 3D emitter use real exhaust position and listener on active camera, with calibrated attenuation. Camera-aware EQ and crossfade over 150–300ms; hood/cockpit filter exterior and boost real intake if present, no phantom layer. Smooth 2–4 dB ambience/music duck at high load or scrub. Honor existing master/music/SFX settings, menu/pause and mute. No music unless legally sourced; do not include commercial music.

### B — Recorded engine (engine/)
Manifest-driven per-profile bank, flexible N RPM anchors; use actual RPM, not speed. Blend nearest available on/off anchors with constant-power cos/sin gains, throttle/load smoothing ~80ms, RPM smoothing ~30–60ms; pitch ratio = current RPM / sample anchor RPM, initial cap 0.75–1.35, tune boundary/idle fallback. No extrapolated fake off-load recordings: if unavailable, use real same-layer with reduced volume/EQ and explicitly report. Reject clips with audible speech or unstable tone. Align phases/seams where feasible; never repeatedly restart sample every tick. Limit active voices to 2 per available load layer + optional real intake/whine, bounded transition banks. Use same recording for no more than necessary fallback; preserve distinct Vela/Orion/Kestrel identity. True idle, crank/start/stop, rev limiter, shift clunk, throttle-lift backfire only if recordings actually exist; torque-cut envelope (~80–140ms) without altering physics. Debounce shift on actual gear changes; backfire only on steep lift above 65% RPM and sufficient cooldown, no mandatory pops. Tune by measured gear/RPM trace. External Bungee only if installed and compatible, otherwise native AudioStreamPlayer/3D. Existing synthetic engine controller must not also play.

### C — Tires and surface (tires/)
Read normalized wheel telemetry, grounding and dominant surface; preserve per-wheel information if useful. Road roll separate asphalt/gravel/grass where assets actually available, speed-dependent gain, fade between surfaces, no roll when airborne. Scrub slip 0.15–0.45, squeal >0.45 with hysteresis, attack ~80ms release ~180ms, speed gate to avoid stationary squeal; handbrake and actual longitudinal slip considered. Only use recorded screech file for high-slip; scrub slot stays null until a credible recording exists or clearly documented filtered derivative is accepted. Dirt/grass use friction-appropriate sound, not screaming asphalt rubber. No hard restart on surface change.

### D — Chassis, world and acoustics (chassis/)
Wind onset ~22m/s with exponential/smooth gain; separate ambient mountain wind from actual aero recording. Add region-aware ambience if real beds available; crossfade spatially across Alder Town, Cedar Woods, North Ridge, Green Valley, Eastwater Lake. Suspension compression velocity from spring length delta/delta time; grounded contact or landing event, strength curve and ~0.16s cooldown. Collision strength from reliable contact impulse if exposed, otherwise explicitly labelled relative-speed estimate with cooldown ~0.12s; cap voices, no contact spam, avoid reset-triggered impacts. Randomized real impact files, separate scrape loop if found. Reflection raycasts left/right/up (~20m) every 4 physics ticks, exclude own vehicle and ground, measure actual closest wall distance; smoothly map distance to delay ~15–120ms (round trip distance / speed of sound where applicable) and wet gain, clamp and bypass in open spaces. Limit global reflection effect to player; no NPC bus contention. Doppler physics-step for moving remote 3D sources only; avoid self-Doppler for player-attached listener. No audio API changes to physics.
