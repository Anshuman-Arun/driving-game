## Budget and release gates
Target 1080p Medium, 60 FPS (16.67 ms deadline) on actual reference Windows GPU; existing baseline below this in places. Begin near 0–25 m, mid 25–65 m, far 65–130 m on Medium, ~12–16 m chunks, 15–25 small tufts/m² as upper experimental sweep not requirement. Start lower, measure density/overdraw/triangle caps. Low/Medium/High adjustable. Design stable world-space seeds, fixed memory and instance cap, hysteresis/fade, predictive prefetch using speed, budgeted main-thread uploads and no whole-map near detail. Grass shadows off initially; optional near shadow test, prefer opaque narrow geometry and alpha scissor over blend when appropriate. Avoid full-world dynamic GI, compute shaders/native extensions or global costly post effects unless measured case. No per-blade physics. Cloud tests must enforce caps, bounded work, determinism, mask correctness, clearance, lifecycle and failure paths. Local capture target: matched stationary, on-road 40–60 mph, fast 100–136 mph where safe, off-road, Cedar and Green Valley then all five regions, real traffic and audio on. Capture native resolution, same speed/pose/FOV/time/preset/car and renderer, actual FPS/CPU/GPU p50/p95/p99/1% low, VRAM, counts; A/B off/on features. Local decides density, color, grass silhouettes, shadows, camera, art quality and actual performance; target p95 frame interval <=16.67 ms if feasible and p99 <=25 ms provisional; if baseline misses, report regression against same run, optimize rather than relaxing target or hiding resolution changes. No release without real local acceptance and passing existing regressions.
