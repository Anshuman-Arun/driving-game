# Environment art and runtime integration notes

## Sources and coordinate contract

All scenery placements use Godot meters (+Y up, east +X, south +Z), 2x2 km bounds X/Z from -1000 to +1000. Source seed: 20261121. World PR #3 supplies five real region centers/radii, six original landmark anchors, the 501x501 uint16 LE R16 cm heightfield at 4m spacing, 16 physical corridor centerlines and 72 intersection turn paths. The World Runtime PR #16 read-only API supplies triangulated terrain height and the exact graph; no source data or interface is overwritten.

Art PR #7 supplies 13 reused original low-poly environment GLBs. Eight additional project-original CC0 embedded glTFs are confined to content/scenery/models/ and generated by tools/models.mjs. No third-party provenance ambiguity is introduced.

Race Content PR #10 supplies the real 102 checkpoint/start-grid/start/finish circular volumes. A pinned snapshot is in avoidance/race_gate_reservations_v1.json; the generator and validator reserve each marker plus its model footprint and an additional 2.5m margin. The module does not create or modify race gameplay.

## Five distinct compositions and the quarry district

| World region | Composed visual signature |
| --- | --- |
| Alder Town | Recognizable garage, compact streetwall houses on multiple actual named streets, lamp-lit civic thresholds, corner visibility buffers and planted outskirts |
| Cedar Woods | Seven unequal conifer groups with natural density pockets, broad terrain depth, Cedar Stone Arch, and a separately authored **Old Quarry** district with spoil rocks, safety barriers and industrial hopper |
| North Ridge | Exposed stone-heavy silhouettes, sparse pine pockets, road-parallel guardrail groups, warning markers, and a view kept clear at Starfall Overlook |
| Green Valley | Open meadows, deliberate asymmetric orchard rows/gaps, broadleaf groves, hay and fence groups, farm buildings, windmill skyline |
| Eastwater Lake | R16-surveyed shallow connected basin, shore scrub/rocks, lakeside roadside views and a surveyed low-water pier-like shore platform |

The six canonical landmarks are *layout anchors* in the original metadata, rather than forced pivots for every large scenery mesh. The authoring tool picks safe sites within 90m of anchor coordinates, avoiding wide road junction pads and rejecting slopes/footprint relief unsafe for structures. This intentionally keeps the original landmark identity without floating buildings or obstructed roads. The exact placed pivots are recorded in the JSON packs.

This is deliberately clustered composition and authored roadside structure; background infill is seeded and non-uniform. The first-pass art is stylized low-poly, not photorealistic.

## Independent geometry and metrics

The generator reads the true World PR #3 R16 and both directions of each physical road to construct physical centerline geometry. Its deterministic --check compares all generated JSON and SVG bytes. The separate validator checks every placement's real triangle-interpolated height, road and 72 turn buffers, 11 junction node protection zones, slope, building footprint relief, the 102 real race exclusions, and non-floating shoreline quads. The lake uses connected low-elevation cells only: water level 5.35m (source minimum5.00m), 5143 quads and 10286 tris, no collision.

The renderer partitions into 128m spatial cells and instantiates each actual glTF/GLB mesh component via MultiMesh. Pine LOD switches detail in near/far rings; landmark view ranges are longer. Camera culling runs every 0.25s. Density presets are deterministic and preserve landmarks/critical road-safety props. Estimated full-world component draws are worst-case all-cell source asset counts, **not** live GPU draw calls. Culling, frustum tests, shadow passes, materials and post-processing affect real results.

## Integrator verification gates

Only the root-project integrator should merge World, Art, Race, World Runtime or core branches or modify root project scenes. The scenery work remains isolated and unmerged until reviewed. Once dependencies are ready, call the loader as shown in modules/scenery/README.md, perform Godot 4.7.2 import and smoke, then inspect geometry and silhouette framing in each region, particularly Town, Starfall, Eastwater and Quarry. Benchmark RTX 4050 1080p Forward+ draw calls, FPS and VRAM from actual driving/chase camera with traffic; none of these are source-only proof of performance.
