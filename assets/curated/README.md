# Aster Valley original curated art library

This source-controlled library contains six primary original fictional vehicle GLBs with four independent wheel pivots, eighteen embedded-glTF environment models, fourteen tileable procedural albedo/normal PNGs, seven Godot PBR material presets, six preserved source vehicle glTFs, model-derived SVG previews and a local gallery.

Additional original alternative vehicle, traffic LOD and pine GLBs were contributed concurrently to the same branch and should be selected after visual/runtime verification. See `MANIFEST.json` for primary asset records and any supplementary variants.

For usage and wheel orientation read `INTEGRATION_NOTES.md`; for reuse rights read `ORIGINAL_ASSETS_LICENSE.md`; for tests and limitations see `tools/asset_pipeline/TEST_REPORT.md`. The gallery is `previews/gallery.html`.
