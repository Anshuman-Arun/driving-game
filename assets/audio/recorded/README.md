# Recorded driving audio — source and audition library
This additive pack does not change game code or the existing synthetic audio module. Run `python tools/recorded_audio/acquire.py` (Python 3.10+, FFmpeg on PATH); `--verify` checks installed WAV hashes and format offline. The branch-only CI acquires and commits verified WAVs under `payload/`. Use the generated `LICENSES_AND_HASHES.json` and per-engine manifests, not assumed file names. 48 kHz mono PCM16, common headroom for each engine bank. Resampling is not restoration of source quality.

Vela: flat-six recorded RPM bank; Kestrel: V8 recorded RPM bank; both are candidate excerpts with CC BY 3.0 upstream credits and estimated RPM/load tags, not studio dyno takes. Check original license review and audible quality before approving. Orion: a CC0 original-car-recording-derived pitch bank is a TEMPORARY recorded fallback, not a distinct real four-cylinder multi-load recording. A high-quality CC0 Mini contact-mic original is linked in catalog but requires login; never invent it as installed. The effects catalog includes real gravel, mountain wind, tire squeal and CC0 impact pack. Source MP3s are labeled as lossy; impacts need audition. Some optional roles may be absent; no placeholder synth allowed.

Keep credits in distributed build; CC BY 3.0 https://creativecommons.org/licenses/by/3.0/; CC0 https://creativecommons.org/publicdomain/zero/1.0/. Never use ripped commercial game samples. See `prompts/AUDIO_SWARM_RECORDED.md` for full integration instructions and quality gates. Do not claim Godot playback or final mix quality from acquisition success.
